## 🏭 Projeto em Destaque

### 🔥 Fluxo (WIP)

Plataforma IoT projetada para conectar dispositivos, redes de comunicação e sistemas de software, viabilizando telemetria, monitoramento e automação em cenários reais como indústria, agro e laboratório.

🔗 [Ver repositório no GitHub](https://github.com/hard87/fluxo-iot-platform) · [![CI](https://github.com/hard87/fluxo-iot-platform/actions/workflows/ci.yml/badge.svg)](https://github.com/hard87/fluxo-iot-platform/actions/workflows/ci.yml)

✅ CI com testes .NET, frontend e E2E · ADRs documentados

**Status:** 🚧 Em desenvolvimento ativo

**Stack:**

* C# / ASP.NET Core (API, Clean Architecture)
* PostgreSQL
* MQTT / HTTP (Mosquitto com TLS)
* React + TypeScript (portal web)
* ESP32 / dispositivos embarcados e gateway Raspberry Pi (em piloto)

**Ambientes:**

* Teste local: Docker Compose
* Produção controlada: Linux / Proxmox (em teste)
* Demo real: VPS (planejado, ainda em definição)
